# 🤖 AI-Based Tic Tac Toe Game

## Deploy Link : (https://ai-based-tic-tac-toe-game.netlify.app/)

## 📌 Description

An interactive Tic Tac Toe game where a human player competes against an AI opponent. The AI makes intelligent moves based on game logic to provide a challenging experience.

## 🚀 Features

* Human vs AI gameplay
* Smart move selection by AI
* Win, lose, and draw detection
* Game reset functionality
* Interactive and responsive UI

## 🧠 AI Logic

* The AI analyzes available moves
* Chooses optimal positions to win or block the opponent
* Implements basic decision-making logic (Minimax / rule-based strategy)

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

✨ This project demonstrates problem-solving skills, game logic, and basic AI implementation using JavaScript.
